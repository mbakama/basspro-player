# Guide Utilisateur - BassPro Player

## Bienvenue dans BassPro Player

BassPro Player est un lecteur de musique professionnel pour Android qui combine la lecture de musique locale avec le streaming en ligne. L'application dispose d'un égaliseur 10 bandes de qualité professionnelle avec amélioration des basses et protection anti-saturation.

## Premiers Pas

### Installation

1. Téléchargez le fichier APK depuis la page des versions
2. Activez "Sources inconnues" dans les paramètres Android
3. Ouvrez le fichier APK et suivez les instructions d'installation
4. Accordez les permissions de stockage lorsque demandé
5. Lancez BassPro Player

### Premier Lancement

Lors du premier lancement, l'application va :

1. **Demander les permissions** : Accordez l'accès au stockage pour scanner votre musique
2. **Scanner votre bibliothèque** : L'application recherche automatiquement tous les fichiers audio sur votre appareil
3. **Afficher votre musique** : Une fois le scan terminé, votre bibliothèque s'affiche dans l'onglet Bibliothèque

Le scan initial peut prendre quelques minutes selon la taille de votre collection musicale.

### Interface Principale

L'application utilise une navigation par onglets en bas de l'écran :

- **📚 Bibliothèque** : Votre musique locale
- **📻 Streaming** : Sources de streaming en ligne
- **🎼 Playlists** : Vos playlists personnalisées
- **⚙️ Paramètres** : Configuration de l'application

## Bibliothèque Musicale

### Navigation dans la Bibliothèque

L'onglet **Bibliothèque** vous permet d'explorer votre musique de trois façons :

#### 🎵 Chansons
- Liste complète de tous vos morceaux
- Affiche le titre, l'artiste, la durée et la pochette
- Appuyez sur un morceau pour le lire immédiatement

#### 👤 Artistes
- Parcourez votre musique par artiste
- Appuyez sur un artiste pour voir tous ses morceaux

#### 💿 Albums
- Parcourez votre musique par album
- Affiche la pochette et le nombre de morceaux
- Appuyez sur un album pour voir son contenu

### Recherche

1. Appuyez sur l'icône de recherche 🔍 en haut de l'écran
2. Tapez votre recherche
3. Les résultats s'affichent en temps réel
4. La recherche fonctionne sur les titres, artistes et albums

### Tri

Triez votre bibliothèque selon vos préférences :

- **Titre** : Ordre alphabétique par titre
- **Artiste** : Ordre alphabétique par artiste
- **Album** : Ordre alphabétique par album
- **Date d'ajout** : Du plus récent au plus ancien
- **Durée** : Du plus court au plus long

Appuyez sur le menu de tri en haut de l'écran pour changer l'ordre.

### Favoris

Marquez vos morceaux préférés pour un accès rapide :

1. Appuyez longuement sur un morceau
2. Sélectionnez "Ajouter aux favoris" ⭐
3. Accédez à vos favoris via la playlist intelligente "Favoris"

Pour retirer un favori, répétez l'opération et sélectionnez "Retirer des favoris".

### Statistiques d'Écoute

L'application suit automatiquement vos habitudes d'écoute :

- **Récemment écoutés** : Les morceaux que vous avez écoutés récemment
- **Les plus écoutés** : Vos morceaux les plus joués

Accédez à ces listes via les playlists intelligentes.

### Rescanner la Bibliothèque

Si vous ajoutez de nouveaux fichiers audio :

1. Allez dans **Paramètres** ⚙️
2. Appuyez sur "Rescanner la bibliothèque"
3. Attendez que le scan se termine
4. Vos nouveaux morceaux apparaissent dans la bibliothèque

## Lecture Audio

### Contrôles de Base

#### Mini Lecteur

Le mini lecteur apparaît en bas de l'écran pendant la lecture :

- **Pochette miniature** : Affiche l'artwork du morceau actuel
- **Titre et artiste** : Informations du morceau en cours
- **⏮️ Précédent** : Retour au morceau précédent
- **⏯️ Lecture/Pause** : Contrôle la lecture
- **⏭️ Suivant** : Passer au morceau suivant

**Astuce** : Appuyez n'importe où sur le mini lecteur pour ouvrir l'écran de lecture complet.

#### Écran de Lecture Complet

Appuyez sur le mini lecteur pour accéder à l'écran de lecture complet :

- **Grande pochette** : Artwork en plein écran
- **Informations du morceau** : Titre, artiste, album
- **Barre de progression** : Position actuelle et durée totale
- **Contrôles principaux** :
  - 🔀 Aléatoire
  - ⏮️ Précédent
  - ⏯️ Lecture/Pause (grand bouton central)
  - ⏭️ Suivant
  - 🔁 Répétition
- **Actions secondaires** :
  - ⭐ Favori
  - ➕ Ajouter à la file d'attente
  - 🎚️ Ouvrir l'égaliseur

#### Gestes

- **Glisser vers le bas** : Fermer l'écran de lecture
- **Glisser vers la gauche** : Morceau suivant
- **Glisser vers la droite** : Morceau précédent
- **Glisser la barre de progression** : Avancer/reculer dans le morceau

### Modes de Lecture

#### Mode Aléatoire 🔀

Active la lecture aléatoire de votre file d'attente :

1. Appuyez sur le bouton Aléatoire 🔀
2. L'ordre des morceaux est mélangé
3. Appuyez à nouveau pour désactiver et restaurer l'ordre original

#### Mode Répétition 🔁

Trois modes disponibles :

1. **Désactivé** : Lecture normale, s'arrête à la fin
2. **Répéter tout** 🔁 : Recommence la file d'attente à la fin
3. **Répéter un** 🔂 : Répète le morceau actuel en boucle

Appuyez sur le bouton Répétition pour cycler entre les modes.

### File d'Attente

La file d'attente contient les morceaux à venir :

#### Voir la File d'Attente

1. Depuis l'écran de lecture, appuyez sur l'icône de file d'attente
2. Voyez tous les morceaux en attente
3. Le morceau actuel est mis en évidence

#### Gérer la File d'Attente

- **Ajouter** : Appuyez longuement sur un morceau → "Ajouter à la file d'attente"
- **Réorganiser** : Maintenez et glissez un morceau pour le déplacer
- **Supprimer** : Glissez un morceau vers la gauche
- **Vider** : Appuyez sur "Vider la file d'attente"

### Lecture en Arrière-Plan

BassPro Player continue de jouer même quand vous utilisez d'autres applications :

#### Notification

Une notification persistante affiche :
- Pochette et informations du morceau
- Contrôles : Précédent, Lecture/Pause, Suivant
- Appuyez sur la notification pour ouvrir l'application

#### Écran de Verrouillage

Les contrôles apparaissent sur l'écran verrouillé :
- Pochette en grand format
- Titre et artiste
- Contrôles de lecture

#### Boutons Média

Les boutons de vos écouteurs et appareils Bluetooth fonctionnent :
- **Lecture/Pause** : Un appui
- **Suivant** : Double appui
- **Précédent** : Triple appui

### Gestion des Interruptions

L'application gère intelligemment les interruptions :

- **Appel téléphonique** : Pause automatique, reprend après l'appel
- **Notification** : Baisse le volume temporairement
- **Autre application audio** : Pause si nécessaire

## Égaliseur

L'égaliseur professionnel 10 bandes vous permet de personnaliser le son selon vos préférences.

### Accéder à l'Égaliseur

1. Ouvrez l'écran de lecture complet
2. Appuyez sur le bouton Égaliseur 🎚️
3. L'égaliseur s'ouvre en modal

### Contrôles de l'Égaliseur

#### Préampli

Le préampli contrôle le volume général avant l'égalisation :

- **Plage** : -10 dB à +10 dB
- **Utilisation** : Augmentez pour plus de volume, baissez pour éviter la saturation
- **Conseil** : Commencez à 0 dB et ajustez selon vos besoins

#### 10 Bandes de Fréquences

Ajustez chaque bande individuellement :

- **32 Hz** : Sub-bass profond (ressenti plus qu'entendu)
- **64 Hz** : Bass très grave
- **125 Hz** : Bass grave
- **250 Hz** : Bass moyen
- **500 Hz** : Bas-médium
- **1 kHz** : Médium
- **2 kHz** : Haut-médium
- **4 kHz** : Présence
- **8 kHz** : Brillance
- **16 kHz** : Air et espace

**Plage** : -10 dB à +10 dB pour chaque bande

#### Sub-Bass et Bass

Contrôles dédiés pour les basses fréquences :

- **Sub-Bass** : Boost les fréquences en dessous de 60 Hz
- **Bass** : Boost les fréquences entre 60 Hz et 250 Hz
- **Plage** : 0 dB à +10 dB

**Conseil** : Utilisez ces contrôles pour un boost de basses puissant et propre.

#### Limiteur

Le limiteur protège contre la saturation audio :

- **Activé** (recommandé) : Réduit automatiquement le gain pour éviter la distorsion
- **Désactivé** : Aucune protection, risque de saturation

**⚠️ Avertissement** : Un indicateur rouge apparaît si le gain total risque de causer une saturation.

### Préréglages

#### Préréglages Intégrés

8 préréglages professionnels inclus :

1. **Deep Bass** 🔊
   - Emphasis maximale sur les sub-bass
   - Idéal pour : Hip-hop, EDM, Dubstep
   - Caractéristique : Basses très profondes et puissantes

2. **Punch Bass** 👊
   - Punch de bass moyen puissant
   - Idéal pour : Rap, Trap, Bass music
   - Caractéristique : Impact et punch dans les basses

3. **Hip-Hop** 🎤
   - Optimisé pour le hip-hop et le rap
   - Idéal pour : Hip-hop, Rap, R&B
   - Caractéristique : Basses profondes avec clarté vocale

4. **EDM** 🎧
   - Profil pour musique électronique
   - Idéal pour : House, Techno, Trance, EDM
   - Caractéristique : Basses puissantes et aigus brillants

5. **Rock** 🎸
   - Emphasis rock et metal
   - Idéal pour : Rock, Metal, Hard rock
   - Caractéristique : Médiums présents et aigus clairs

6. **Pop** 🎵
   - Profil équilibré pour la pop
   - Idéal pour : Pop, Dance, Top 40
   - Caractéristique : Son équilibré et agréable

7. **Vocal Clarity** 🎙️
   - Fréquences vocales améliorées
   - Idéal pour : Podcasts, Audiobooks, Ballades
   - Caractéristique : Voix claires et intelligibles

8. **Balanced** ⚖️
   - Réponse plate (aucun ajustement)
   - Idéal pour : Musique classique, Jazz, Audiophiles
   - Caractéristique : Son naturel et non coloré

#### Sélectionner un Préréglage

1. Ouvrez l'égaliseur
2. Appuyez sur le menu déroulant "Préréglage"
3. Sélectionnez le préréglage désiré
4. Tous les réglages s'appliquent instantanément

#### Créer un Préréglage Personnalisé

1. Ajustez l'égaliseur selon vos préférences
2. Appuyez sur "Enregistrer le préréglage"
3. Donnez un nom à votre préréglage
4. Appuyez sur "Enregistrer"
5. Votre préréglage apparaît dans la liste

#### Supprimer un Préréglage

1. Sélectionnez le préréglage personnalisé
2. Appuyez longuement sur le nom
3. Sélectionnez "Supprimer"
4. Confirmez la suppression

**Note** : Les préréglages intégrés ne peuvent pas être supprimés.

### Conseils d'Utilisation

#### Pour des Basses Puissantes

1. Sélectionnez le préréglage "Deep Bass" ou "Punch Bass"
2. Ajustez Sub-Bass et Bass selon vos préférences
3. Baissez le préampli si l'avertissement de saturation apparaît
4. Activez le limiteur pour une protection maximale

#### Pour Éviter la Saturation

1. Gardez le limiteur activé
2. Ne montez pas toutes les bandes au maximum
3. Baissez le préampli si vous boostez plusieurs bandes
4. Surveillez l'indicateur d'avertissement rouge

#### Pour la Musique Classique

1. Sélectionnez le préréglage "Balanced"
2. Faites des ajustements subtils (±2-3 dB maximum)
3. Privilégiez la clarté à la puissance

#### Pour les Podcasts

1. Sélectionnez le préréglage "Vocal Clarity"
2. Boostez légèrement 1-4 kHz pour la clarté vocale
3. Réduisez les basses pour moins de rumble

### Application en Temps Réel

Tous les ajustements s'appliquent instantanément pendant la lecture :

- Pas besoin de redémarrer le morceau
- Testez différents réglages en direct
- Fonctionne pour la musique locale et le streaming

## Playlists

Les playlists vous permettent d'organiser votre musique par thème, humeur ou occasion.

### Types de Playlists

#### Playlists Intelligentes

Générées automatiquement par l'application :

1. **⭐ Favoris**
   - Tous vos morceaux favoris
   - Mise à jour automatique quand vous ajoutez/retirez des favoris

2. **🆕 Récemment ajoutés**
   - Morceaux ajoutés récemment à votre bibliothèque
   - Triés par date d'ajout (plus récent en premier)

3. **🔥 Les plus écoutés**
   - Vos morceaux les plus joués
   - Triés par nombre d'écoutes (plus écouté en premier)

#### Playlists Personnalisées

Créées et gérées par vous :

- Nombre illimité de playlists
- Ajoutez n'importe quel morceau
- Organisez l'ordre comme vous voulez

### Créer une Playlist

1. Allez dans l'onglet **Playlists** 🎼
2. Appuyez sur le bouton "+" ou "Créer une playlist"
3. Entrez un nom pour votre playlist
4. Appuyez sur "Créer"
5. Votre nouvelle playlist apparaît dans la liste

### Ajouter des Morceaux

#### Depuis la Bibliothèque

1. Appuyez longuement sur un morceau
2. Sélectionnez "Ajouter à une playlist"
3. Choisissez la playlist de destination
4. Le morceau est ajouté à la fin de la playlist

#### Depuis l'Écran de Lecture

1. Appuyez sur le bouton "+" dans l'écran de lecture
2. Sélectionnez "Ajouter à une playlist"
3. Choisissez la playlist
4. Le morceau actuel est ajouté

### Gérer une Playlist

#### Voir le Contenu

1. Appuyez sur une playlist dans l'onglet Playlists
2. Tous les morceaux s'affichent dans l'ordre
3. Voyez le nombre total de morceaux en haut

#### Réorganiser les Morceaux

1. Ouvrez la playlist
2. Maintenez le doigt sur un morceau
3. Glissez-le vers le haut ou le bas
4. Relâchez à la position désirée

#### Supprimer un Morceau

1. Ouvrez la playlist
2. Glissez un morceau vers la gauche
3. Appuyez sur "Supprimer"
4. Le morceau est retiré de la playlist (pas de votre bibliothèque)

#### Renommer une Playlist

1. Appuyez longuement sur la playlist
2. Sélectionnez "Renommer"
3. Entrez le nouveau nom
4. Appuyez sur "Enregistrer"

#### Supprimer une Playlist

1. Appuyez longuement sur la playlist
2. Sélectionnez "Supprimer"
3. Confirmez la suppression
4. La playlist est supprimée (les morceaux restent dans votre bibliothèque)

**Note** : Les playlists intelligentes ne peuvent pas être supprimées.

#### Lecture Complète

1. Ouvrez la playlist
2. Appuyez sur le bouton "Lire tout" ▶️
3. Tous les morceaux sont ajoutés à la file d'attente
4. La lecture commence au premier morceau

#### Lecture d'un Morceau Spécifique

1. Ouvrez la playlist
2. Appuyez sur le morceau désiré
3. La lecture commence à ce morceau
4. Les morceaux suivants de la playlist sont ajoutés à la file d'attente

#### Lecture Aléatoire

1. Ouvrez la playlist
2. Appuyez sur "Lire tout"
3. Activez le mode aléatoire 🔀
4. Les morceaux sont joués dans un ordre aléatoire

## Streaming

Le streaming vous permet d'écouter des radios internet et des podcasts en ligne.

### Ajouter une Source de Streaming

1. Allez dans l'onglet **Streaming** 📻
2. Appuyez sur le bouton "+" ou "Ajouter un flux"
3. Remplissez les informations :
   - **Nom du flux** : Nom de la station (ex: "Radio Jazz")
   - **URL du flux** : Adresse du stream (ex: http://stream.radio.com/jazz)
   - **Catégorie** (optionnel) : Genre ou type (ex: "Jazz", "Actualités")
4. Appuyez sur "Enregistrer"
5. La source apparaît dans votre liste

### Trouver des URLs de Streaming

#### Radios Internet

- Visitez le site web de la radio
- Cherchez "Écouter en direct" ou "Listen Live"
- Copiez l'URL du flux (souvent en .mp3, .aac, ou .pls)

#### Formats Supportés

- HTTP/HTTPS direct (http://example.com/stream.mp3)
- Icecast/Shoutcast streams
- Fichiers audio directs

**Note** : Les streams nécessitant une authentification ne sont pas supportés.

### Lire un Stream

1. Appuyez sur une source de streaming
2. L'application se connecte au flux
3. Un indicateur de chargement apparaît pendant la connexion
4. La lecture commence automatiquement

### Gérer les Sources

#### Marquer comme Favori

1. Appuyez longuement sur une source
2. Sélectionnez "Ajouter aux favoris" ⭐
3. La source apparaît dans la section "Favoris"

#### Modifier une Source

1. Appuyez longuement sur une source
2. Sélectionnez "Modifier"
3. Changez le nom, l'URL ou la catégorie
4. Appuyez sur "Enregistrer"

#### Supprimer une Source

1. Appuyez longuement sur une source
2. Sélectionnez "Supprimer"
3. Confirmez la suppression
4. La source est retirée de votre liste

### Historique de Streaming

La section "Récemment écoutés" affiche :
- Les streams que vous avez écoutés récemment
- Triés par date d'écoute (plus récent en premier)
- Accès rapide à vos stations préférées

### Gestion des Erreurs

#### Stream Inaccessible

Si un stream ne fonctionne pas :

1. **Vérifiez votre connexion internet**
   - Assurez-vous d'être connecté au Wi-Fi ou aux données mobiles
   - Testez avec un navigateur web

2. **Vérifiez l'URL**
   - L'URL est-elle correcte ?
   - Le stream est-il toujours actif ?

3. **Réessayez**
   - Appuyez sur "Réessayer" dans le message d'erreur
   - Ou fermez et relancez le stream

#### Connexion Perdue

Si la connexion est perdue pendant l'écoute :

1. L'application met en pause automatiquement
2. Un message d'erreur s'affiche
3. Appuyez sur "Réessayer" quand la connexion revient
4. Ou appuyez sur Lecture pour relancer manuellement

#### Chargement Long

Si le stream met du temps à démarrer :

- **Connexion lente** : Attendez quelques secondes
- **Stream surchargé** : Réessayez plus tard
- **Problème de stream** : Essayez une autre source

### Conseils de Streaming

#### Économiser les Données

- Utilisez le Wi-Fi quand possible
- Les streams audio consomment environ 1-2 MB par minute
- Surveillez votre forfait data si vous utilisez les données mobiles

#### Qualité Audio

- La qualité dépend du stream source
- Les streams en 128 kbps ou plus offrent une bonne qualité
- Les streams en 320 kbps offrent une qualité maximale

#### Stabilité

- Une connexion stable est importante pour le streaming
- Le Wi-Fi est généralement plus stable que les données mobiles
- Évitez les zones avec une mauvaise réception

### Égaliseur et Streaming

L'égaliseur fonctionne aussi avec le streaming :

1. Lancez un stream
2. Ouvrez l'égaliseur
3. Ajustez les réglages comme pour la musique locale
4. Les changements s'appliquent en temps réel

Empêche l'écran de s'éteindre pendant la lecture :

- **Activé** : L'écran reste allumé pendant la lecture
- **Désactivé** : L'écran s'éteint normalement

**Utilisation** :
- Activez pour voir les contrôles en permanence
- Désactivez pour économiser la batterie
- Utile en voiture ou pendant le sport

**Changer le réglage** :
1. Appuyez sur le bouton à bascule
2. Le changement est immédiat

#### Minuterie de Sommeil

Arrête automatiquement la lecture après un délai :

**Options disponibles** :
- Désactivé (par défaut)
- 15 minutes
- 30 minutes
- 45 minutes
- 60 minutes
- 90 minutes

**Activer la minuterie** :
1. Appuyez sur "Minuterie de sommeil"
2. Sélectionnez une durée

1. Retournez dans Paramètres
2. Sélectionnez "Désactivé"
3. Le compte à rebours disparaît

**Fonctionnement** :
- Le compte à rebours continue en arrière-plan
- Fonctionne même si vous fermez l'application
- La musique s'arrête en douceur (fondu de 5 secondes)
- Parfait pour s'endormir en musique

## Conseils et Astuces

### Optimiser la Qualité Audio

1. **Utilisez des fichiers de haute qualité**
   - Formats sans perte : FLAC, WAV
   - MP3 320 kbps minimum pour une bonne qualité
   - Évitez les fichiers trop compressés

2. **Ajustez l'égaliseur progressivement**
   - Commencez avec un préréglage
   - Faites des ajustements subtils (±2-3 dB)
   - Écoutez attentivement les changements

3. **Activez le limiteur**
   - Protection contre la saturation
   - Son plus propre à volume élevé
   - Recommandé pour les basses puissantes

4. **Utilisez de bons écouteurs/enceintes**
   - La qualité du matériel audio est importante
   - Les écouteurs de qualité révèlent plus de détails
   - Les enceintes avec bon bass response profitent de l'égaliseur

### Économiser la Batterie

1. **Utilisez le thème sombre**
   - Économise la batterie sur écrans OLED
   - Réduit la consommation d'énergie

2. **Désactivez "Garder l'écran allumé"**
   - Laissez l'écran s'éteindre normalement
   - Utilisez les contrôles de notification

3. **Téléchargez plutôt que streamer**
   - Le streaming consomme plus de batterie
   - La musique locale est plus efficace

4. **Fermez l'application quand vous ne l'utilisez pas**
   - Arrêtez la lecture si vous ne l'écoutez pas
   - L'application en arrière-plan consomme de la batterie

### Organiser Votre Bibliothèque

1. **Utilisez des tags ID3 corrects**
   - Assurez-vous que vos fichiers ont les bonnes métadonnées
   - Utilisez un éditeur de tags si nécessaire
   - Titre, artiste, album bien renseignés

2. **Créez des playlists thématiques**
   - Organisez par genre, humeur, activité
   - Facilitez l'accès à votre musique
   - Gagnez du temps

3. **Marquez vos favoris**
   - Accès rapide à vos morceaux préférés
   - Playlist intelligente automatique
   - Un seul appui long suffit

4. **Rescannez régulièrement**
   - Après avoir ajouté de nouveaux fichiers
   - Gardez votre bibliothèque à jour
   - Supprime les fichiers manquants

### Utilisation Avancée

#### Créer des Préréglages Personnalisés

1. Partez d'un préréglage proche de ce que vous voulez
2. Ajustez bande par bande

#### Gérer une Grande Bibliothèque

## Dépannage

### Problèmes Courants

#### Les fichiers musicaux n'apparaissent pas

**Causes possibles** :
- Permissions de stockage non accordées
- Fichiers dans un format non supporté
- Fichiers dans un emplacement non scanné

**Solutions** :
1. Vérifiez les permissions :
   - Paramètres Android → Applications → BassPro Player → Permissions
   - Accordez l'accès au stockage
2. Vérifiez le format des fichiers :
   - Formats supportés : MP3, M4A, AAC, FLAC, WAV, OGG, OPUS
   - Convertissez si nécessaire
3. Rescannez la bibliothèque :
   - Paramètres → Rescanner la bibliothèque
   - Attendez la fin du scan

#### Le streaming ne fonctionne pas

**Causes possibles** :
- Pas de connexion internet
- URL de stream incorrecte
- Stream temporairement indisponible

**Solutions** :
1. Vérifiez votre connexion :
   - Testez avec un navigateur web
   - Vérifiez le Wi-Fi ou les données mobiles
2. Vérifiez l'URL :
   - Assurez-vous qu'elle est correcte
   - Testez l'URL dans un navigateur
3. Réessayez plus tard :
   - Le stream peut être temporairement hors ligne
   - Essayez une autre source

#### Problèmes de qualité audio

**Causes possibles** :
- Égaliseur mal réglé
- Saturation audio
- Fichiers de mauvaise qualité

**Solutions** :
1. Réinitialisez l'égaliseur :
   - Sélectionnez le préréglage "Balanced"
   - Ou baissez tous les réglages
2. Activez le limiteur :
   - Ouvrez l'égaliseur
   - Activez le limiteur
3. Vérifiez vos fichiers :
   - Utilisez des fichiers de meilleure qualité
   - MP3 320 kbps minimum

#### La lecture en arrière-plan s'arrête

**Causes possibles** :
- Optimisation de batterie trop agressive
- Permissions manquantes
- Mémoire insuffisante

**Solutions** :
1. Désactivez l'optimisation de batterie :
   - Paramètres Android → Batterie → Optimisation de batterie
   - Trouvez BassPro Player
   - Sélectionnez "Ne pas optimiser"
2. Vérifiez les permissions :
   - Notifications autorisées
   - Exécution en arrière-plan autorisée
3. Libérez de la mémoire :
   - Fermez d'autres applications
   - Redémarrez votre appareil

#### L'application plante ou freeze

**Causes possibles** :
- Cache corrompu
- Base de données corrompue
- Mémoire insuffisante

**Solutions** :
1. Videz le cache :
   - Paramètres Android → Applications → BassPro Player
   - Stockage → Vider le cache
2. Rescannez la bibliothèque :
   - Peut réparer la base de données
   - Paramètres → Rescanner la bibliothèque
3. Réinstallez l'application :
   - Sauvegardez vos playlists (notez-les)
   - Désinstallez l'application
   - Réinstallez la dernière version

#### L'égaliseur ne fonctionne pas

**Causes possibles** :
- Appareil ne supporte pas l'égalisation
- Conflit avec autre application audio

**Solutions** :
1. Vérifiez la compatibilité :
   - Tous les appareils ne supportent pas l'égaliseur
   - Testez avec différents préréglages
2. Fermez autres applications audio :
   - Certaines applications peuvent interférer
   - Redémarrez l'appareil

#### Les pochettes ne s'affichent pas

**Causes possibles** :
- Fichiers sans artwork intégré
- Cache d'images corrompu

**Solutions** :
1. Ajoutez des pochettes à vos fichiers :
   - Utilisez un éditeur de tags
   - Intégrez les images dans les fichiers
2. Videz le cache :
   - Paramètres Android → Applications → BassPro Player
   - Stockage → Vider le cache
3. Rescannez :
   - Paramètres → Rescanner la bibliothèque

### Messages d'Erreur

#### "Erreur de connexion réseau"

**Signification** : Impossible de se connecter au stream

**Solution** :
- Vérifiez votre connexion internet
- Réessayez dans quelques instants
- Vérifiez l'URL du stream

#### "Permission refusée"

**Signification** : L'application n'a pas accès au stockage

**Solution** :
- Accordez les permissions dans les paramètres Android
- Relancez l'application

#### "Fichier introuvable"

**Signification** : Le fichier audio a été déplacé ou supprimé

**Solution** :
- Rescannez la bibliothèque
- Le fichier sera retiré de la liste

#### "Format non supporté"

**Signification** : Le format audio n'est pas compatible

**Solution** :
- Convertissez le fichier dans un format supporté
- Utilisez MP3, M4A, FLAC, WAV, OGG, ou OPUS

### Obtenir de l'Aide

Si vous rencontrez un problème non résolu :

1. **Vérifiez la version**
   - Assurez-vous d'avoir la dernière version
   - Paramètres → Version de l'application

2. **Redémarrez l'appareil**
   - Résout souvent les problèmes temporaires
   - Libère la mémoire

3. **Contactez le support**
   - Décrivez le problème en détail
   - Indiquez votre modèle d'appareil
   - Indiquez votre version d'Android
   - Indiquez la version de l'application

## Informations Techniques

### Configuration Requise

- **Système** : Android 5.0 (API 21) ou supérieur
- **Stockage** : Minimum 100 MB d'espace libre
- **RAM** : Minimum 2 GB recommandé
- **Internet** : Requis uniquement pour le streaming

### Formats Audio Supportés

- **MP3** : MPEG Audio Layer 3
- **M4A** : MPEG-4 Audio
- **AAC** : Advanced Audio Coding
- **FLAC** : Free Lossless Audio Codec
- **WAV** : Waveform Audio File Format
- **OGG** : Ogg Vorbis
- **OPUS** : Opus Interactive Audio Codec

### Permissions

L'application demande les permissions suivantes :

- **Stockage** : Accéder à vos fichiers musicaux
- **Internet** : Streaming audio en ligne
- **Service en avant-plan** : Lecture en arrière-plan
- **Wake Lock** : Garder l'écran allumé (optionnel)
- **Contrôle média** : Boutons écouteurs/Bluetooth

BassPro Player respecte votre vie privée :

- ✅ Aucune collecte de données
- ✅ Aucun tracking ou analytics
- ✅ Fonctionne entièrement hors ligne (sauf streaming)
- ✅ Toutes les données stockées localement
- ✅ Aucun compte requis
- ✅ Code source disponible pour vérification
